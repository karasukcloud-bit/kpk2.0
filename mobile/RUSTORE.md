# Публикация в RuStore — СПО-ПРОГРЕСС

Package: `ru.kpk.attendance`  
Версия сборки: **1.5.0** (`versionCode` **15**)

## Артефакты релиза

После `npm run release` в каталоге `mobile/`:

| Файл | Назначение |
|------|------------|
| `android/app/build/outputs/bundle/release/app-release.aab` | предпочтительно для RuStore |
| `android/app/build/outputs/apk/release/app-release.apk` | альтернатива / прямая установка |

Подпись: `mobile/kpk-release.keystore` (пароли в `RELEASE_CREDENTIALS.txt`, **не коммитить**).

## Чеклист перед загрузкой

1. Сделайте резервную копию `kpk-release.keystore` + `RELEASE_CREDENTIALS.txt` (вне репозитория).
2. Убедитесь, что на проде доступны:
   - сайт (HTTPS);
   - `privacy.php` — политика конфиденциальности;
   - `api/mobile_notification_schedules.php` — расписания уведомлений.
3. Подготовьте в RuStore Console:
   - тестовый логин/пароль для модераторов;
   - скриншоты (телефон, ≥ 2–3 шт.): экран PIN, журнал/дашборд, уведомление;
   - иконка 512×512 (`mobile/www/icon-512.png`);
   - краткое и полное описание (черновик ниже);
   - URL политики: `https://ВАШ-ДОМЕН/privacy.php`.
4. В комментарии модератору укажите: «Веб-клиент к системе учёта; для проверки нужен доступ к серверу организации и тестовая учётная запись».

## Текст для витрины (черновик)

**Название:** СПО-ПРОГРЕСС

**Краткое описание:**  
Мобильный доступ к системе учёта посещаемости и успеваемости колледжа. Вход через сайт организации, защита PIN и биометрией, напоминания по расписанию.

**Полное описание:**  
СПО-ПРОГРЕСС — официальная оболочка системы учёта для студентов и сотрудников.

Возможности:
• безопасный вход на сервер организации во встроенном браузере;
• защита приложения PIN-кодом и биометрией устройства;
• локальные уведомления-напоминания по расписанию администратора;
• работа с тем же сайтом, что и в обычном браузере.

Приложение не заменяет сайт: оно открывает ваш корпоративный сервер учёта и хранит сессию на устройстве.

**Категория:** Образование  
**Возраст:** 0+ / для всех (уточните по фактическим правилам организации)

## Разрешения (для описания в консоли)

- Интернет — работа с сервером учёта  
- Биометрия — разблокировка  
- Уведомления и точные будильники — напоминания  
- Автозапуск после перезагрузки — восстановление напоминаний  

## Обновления

Перед каждой новой загрузкой в RuStore увеличивайте только `versionCode` (и при необходимости `versionName`) в `android/app/build.gradle`, затем снова `npm run release`.

Package name и keystore **не менять**.
